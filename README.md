# G Navigation privacy policy — Google Play edition

Static pages served by GitHub Pages at <https://hungsvvl.github.io/g-navigation-privacy/>
(`vi/`, `en/`, `zh/`, `zh-cn/`, `zh-hant/`; the root is Vietnamese). They cover the
G Navigation phone app on Google Play and its Wear OS watch app. No cookies, scripts,
analytics or third-party assets.

The pages are generated from `cloudflare/phone-privacy` in the G Navigation source
(`tools/render-static.mjs --edition=general`); edit the source there, not these files.
